## Working theory
The Home level-up notification emits more than once for the same level (two identical "level-up celebration for level 15" logs), and `LevelUpRoute` is navigated then immediately `go back` — the celebration is pushed and popped back-to-back. That reconciles both symptoms: an instant pop shows the user nothing ("missing", CARDS-7K); a double-emit shows a flash twice ("showed twice", CARDS-7N). Fix: make the notification idempotent per earned level, keep the celebration up until the user dismisses it instead of auto-popping, and add Info-level enqueue/consume logging (the owner's explicit ask) so future misses are diagnosable. Supersedes the retired PROG-3/PROG-5 "celebration missing" todos, which framed it as a purely missing-event bug.
