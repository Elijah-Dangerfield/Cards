## Working theory
In a private (fake-chip) MP room the pot is awarded to the in-table stack, but the player's table stack is not settled back to the persistent wallet (`ChipsRepository` ledger) when they leave — so a won pot shows "nothing" in the wallet, and the later +100 after background/foreground (CARDS-3G) is a partial/late reconcile firing on resume, which is why it looks random. Need a product call on whether private fake-chip rooms are *supposed* to move the wallet at all; if yes this is a settlement bug, if no the table stack must not be framed as the wallet balance. Either way the current behavior (win 500 → wallet unchanged → +100 on resume) is broken and surprising. This is the human-vs-human analogue of the bots-for-chips settlement work (MP-6/CARDS-2N), but that path credits `finalStack` on `cashOut` — the private-room leave path appears to have no equivalent credit.
