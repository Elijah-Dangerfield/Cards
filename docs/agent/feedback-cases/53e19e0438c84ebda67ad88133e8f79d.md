## Working theory
By design, `BustDialog` in `features/room/impl/.../ui/HandResultDialogs.kt` is "Shown **instead of** `ShowdownDialog` when the human's stack hit 0 this hand" (comment at ~L239). So when the human busts at showdown, the showdown result dialog never appears and the table's card-reveal animation plays underneath the bust dialog's scrim — exactly what the reporter describes ("could kinda see the card reveal below the scrim"). Fix direction: sequence the showdown reveal (or `ShowdownDialog`) before presenting the bust dialog, or surface the winning/losing hands inside `BustDialog` itself. Related-but-distinct backlog note exists about these dialogs dismissing on scrim-tap.
