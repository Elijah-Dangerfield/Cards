## Working theory + fix
**Problem 1 — dialog scrim not full-screen.** The GAME-11 fix (commit 06a1900e) wrapped the app-root `DialogHost` in a top-most `Popup` so dialogs clear Material bottom sheets. On skiko (iOS) a `Popup` is inset by the platform safe area by default, so the dialog's `fillMaxSize` scrim stopped at the safe area and read as a floating panel. Fix: pass `usePlatformInsets = false` to the popup so it (and the scrim) cover the whole screen. `usePlatformInsets` only exists on the skiko `PopupProperties`, not Android's, so it's supplied per-platform via a new `expect fun fullScreenDialogPopupProperties()` (`libraries/ui/.../dialog/DialogHostState.kt` + android/ios/jvm actuals). Keeps GAME-11's z-order win.

**Problem 2 — player bet clipped.** The human seat tile stacked the bet amount as a full `ChipPill` *below* the chip count, pushing the column past the locked hole-card row height and clipping it. Fix (see also case 5767dcdb): render the bet via the shared `SeatActionChip` cut into the avatar's bottom edge exactly like the opponent seats — costs no column height, no clip. `features/room/impl/.../ui/PlayerArea.kt`.
