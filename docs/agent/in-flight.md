Kept the `.immediate` semantics rather than collapsing to plain `main` — the existing call lives in a `processingJob` launched on `appScope` (default dispatcher) so `.immediate` is a no-op in production today, but the comment in the file's `setNavController` block (lines 100-108) is defensive about exactly the kind of frame-skip behaviour `.immediate` exists to avoid, so preserving the contract is the safe call. **Source:** worker-hydrated this cycle (not human-curated). Hydrated under §C "Dispatcher hygiene" right before shipping per the worker-hydrator override; removed it after the commit. The hydration item only covered DelegatingRouter, not the three `Dispatchers.Main.immediate` callsites inside `:libraries:flowroutines`'s own `Compose.kt` — those are top-level extension functions in the abstraction module itself, where injecting `DispatcherProvider` would mean threading it through every callsite invasively (each composable consumer would need to acquire and pass one).
