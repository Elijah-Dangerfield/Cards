# In-flight

## feat(room): show bot playing-style archetype on tap-an-opponent sheet

**Problem:** [PlayerProfileSheet.kt](../../features/room/impl/src/commonMain/kotlin/com/cards/features/room/impl/PlayerProfileSheet.kt) had only the title + mute switch. The "bot variant surfaces personality + difficulty tier breakdown" sub-bullet under §A "Expand the tap-an-opponent profile sheet" was open — tapping a bot opponent gave no signal about how they actually play.
**Approach:** Added `personality: BotPersonality?` to [SeatView](../../features/room/impl/src/commonMain/kotlin/com/cards/features/room/impl/TableUiState.kt) (already had `personalitiesBySeat` in the projection — just wasn't surfacing the object). New [BotPlayingStyle.kt](../../features/room/impl/src/commonMain/kotlin/com/cards/features/room/impl/BotPlayingStyle.kt) maps tightness/aggression/bluffRate into one of six archetypes (Tight passive / Tight aggressive / Loose passive / Loose aggressive / Maniac / Balanced) with a one-line gameplay-grounded blurb. Sheet renders a new "Playing style" `ListSection` above Settings for bot seats. Picked the bucket thresholds so each of the five roster bots lands in a distinct archetype (Jane=Tight passive, David=Loose aggressive, Gina=Tight aggressive, Steve=Loose passive, Mike=Maniac) — pinned by [BotPlayingStyleTest.kt](../../features/room/impl/src/commonTest/kotlin/com/cards/features/room/impl/BotPlayingStyleTest.kt) so a future personality tweak that collapses two bots into the same label fails loudly.
**Reviewer notes:** The archetype copy is gameplay-strategic ("value bet, don't bluff"), not flavor — I wrote it cold since no existing canonical bot descriptions exist in the codebase. If the brand voice wants warmer / less prescriptive phrasing, the file is small and self-contained. The `personality` field on SeatView has a default of `null` so MP seats (no local personality) and the human seat just don't render the section.
**Deferred:**
- Difficulty-tier breakdown ("Casual is forgiving / Standard punishes mistakes / Challenging exploits patterns") — left noted in the bullet's remaining-work list. Would need either threading `botDifficultyLabel` through `SeatView` or stashing it on `TableUiState.Active`; small change, but I'd want a designer eyeball on whether table-level difficulty wants its own section or should fold into the existing "Bot · Standard" subtitle in the sheet title.
- "Playing since {createdAt}" + "N hands at the table" + Add-friend + view-full-profile — same bullet, all gated on real MP profile + room-membership plumbing that doesn't exist yet.
