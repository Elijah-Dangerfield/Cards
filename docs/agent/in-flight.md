# In-flight

## feat(auth): route VerifyEmail off resolveIsNewAccount; retire walletJustCreated (AUTH-22)

**Problem:** `VerifyEmailViewModel.isBrandNewAccount()` was the last auth path still classifying new-vs-returning from the best-effort `ChipsRepository.walletJustCreated` proxy (which goes false offline and trips on identity churn), instead of the authoritative server `/v1/me` `isNewAccount` signal that onboarding + the Home welcome already use.
**Approach:** Injected `ProfileRepository` into `VerifyEmailViewModel` (dropped the now-unused `ChipsRepository`) and rewired `isBrandNewAccount()` to `profileRepository.resolveIsNewAccount()`, mirroring `OnboardingViewModel`. With that call site gone, `walletJustCreated` had no remaining production reader, so I retired it end-to-end: removed it from the `ChipsRepository` interface + `ChipsRepositoryImpl` (`_walletJustCreated` field and the `response.walletCreated` flip) and from every test fake across `:libraries:cards:impl`, `:features:{home,shop,room,lobby,onboarding}:impl`, `:libraries:billing:impl`, and `:apps:integration`. Switched `VerifyEmailViewModelTest` to drive `FakeProfileRepository.isNewAccount` (the same knob `OnboardingViewModelTest` uses) and deleted the two `ChipsRepositoryImplSyncTest` cases that asserted the retired flip. Left the server-side / sync-response `walletCreated` DTO field untouched (separate wire concern).
**Reviewer notes:** The client sync-response DTO still deserializes a `walletCreated` field that nothing reads now — harmless and intentionally out of scope (the task scoped removal to the client signal only). The DI change needed no manual factory edit: kotlin-inject regenerates `(email: String?) -> VerifyEmailViewModel` and `ProfileRepository` was already in the onboarding graph; confirmed by a green `:apps:compose:assembleDebug`.
**Deferred:** AUTH-22's optional part (b) — a single typed `AuthOutcome` (`SignedUp`/`SignedIn`/`Linked`) from the auth layer — is not done; I rewrote the todo bullet (kept the AUTH-22 ID, dropped to P2) to describe just that remaining polish. The `walletJustCreated` half of its acceptance is now fully satisfied.
