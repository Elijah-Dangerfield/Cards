**Approach:** Two-file change, no plumbing changes. New [EarnableCosmeticsTest.kt](../../libraries/cards/impl/src/commonTest/kotlin/com/cards/libraries/cards/impl/EarnableCosmeticsTest.kt) pins all four current mappings + spot-checks the no-reward path. Updated `docs/todo.md` to flag the bullet as partially landed with the remaining "dedicated full-bleed dialog after dismiss" work called out explicitly.
**Reviewer notes:** I deliberately picked the smaller of the two options. The bullet says "dialog" and "prestige lives at earn-time", which suggests a dedicated full-screen celebration sequenced after the showdown dismisses; doing that would have cut into VM action sequencing + animation work that pairs with the "XP / coin earned distribution animation" bullet, which itself is queued. The mapping table on the client is a duplicate of the server's allowlist — the test will fail loudly if either side drifts, and the file's KDoc points at the server source of truth so the next worker who touches one finds the other.
**Deferred:**
