**AUTH-12 (Google claim still shows "sign in and claim"):** Deferred, not shipped. The repository layer already carries the documented fix — `completeOAuthRedirect`'s Link path force-`refreshSession()`s and `SupabaseAuthRepositoryImplTest.linkOAuthIdentity_redirect_refreshesSession_evenWhenHydrateAloneLeavesAnonymous` (green) models the exact device scenario. Every in-app claim CTA I traced observes `authRepository.observe()` or `/v1/me`'s `isAnonymous` (server-authoritative off the JWT claim), both of which flip correctly once the refreshed token is in use. The residual cause is at the supabase-kt seam: client `isAnonymous` is derived from `user.identities.isNullOrEmpty()` in `RealSupabaseAuthGateway.currentSession()`, whose repopulation after a link+refresh is version/device-dependent and not reproducible in a `CoroutineTest` (the fake gateway models "refresh flips it," which the repo already handles). Confidently fixing this needs device observation of supabase-kt 3.6 behavior; forcing a speculative change risks regressing the green suite. Candidate robust fix for a human to weigh: derive `isAnonymous` from the JWT `is_anonymous` claim (the authoritative signal the server trusts) instead of the identities heuristic.

**GAME-11 (feedback dialog behind bottom sheets):** Real bug, not shipped this cycle. Root cause confirmed: the shake "sun" dial (`ShakeDialogRoute`) and `FeedbackRoute` are presented as NavHost `dialog<>`/`screen<>` inside the graph, so a `ModalBottomSheet` (a floating window) can occlude them. The app already has the right primitive — the app-root `DialogHost` (App.kt, drawn above `AppNavigation`) renders `DialogHostState` entries above the NavHost's floating windows. The proper fix re-plumbs the shake→feedback presentation to drive the app-root `DialogHost` (or an equivalent top-most overlay) off `ShakeHandler` state instead of `router.navigate(...)`. Held off because it's an app-shell restructure and the defect is a platform window z-order concern that isn't reproducible in a unit test (no cheap red test), so it wants a deliberate design pass rather than a rushed patch.
